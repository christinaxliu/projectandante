This is the git repository for ***PROJECT ANDANTE*** (https://www.projectandante.org), a youth-run nonprofit organization that provides a platform for talented young musicians performing concerts at senior living centers. Established in 2022, we have had:
- **331** individual performances in our concerts
- **106** unique performers from different schools
- **30** concerts held in senior living centers around the Seattle metropolitan area

I designed and built the website for our organization (https://www.projectandante.org). This git repository contains the source code for the javascript code (both backend and frontend) and SQL scripts:
- The javascript code for the service running at the backend, as well as the frontend code that runs at the client side web browser to connect to the backend and database and generates dynamic web content: https://github.com/christinaxliu/projectandante/tree/main/javascript
- SQL for MySQL database table creation, managing and retrieving data from database: https://github.com/christinaxliu/projectandante/tree/main/mysql
